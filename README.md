# Site Institucional - Castanhas & Torresmo

Site institucional moderno e responsivo para empresa de alimentos artesanais (Castanhas e Torresmo).

## 🎨 Características

- **Design Moderno**: Interface limpa e apetitosa com cores terrosas
- **Responsivo**: Mobile-first, totalmente adaptável a todos os dispositivos
- **Navegação Intuitiva**: Menu hambúrguer para mobile e navbar fixa
- **Modais Interativos**: Visualização de produtos em atacado (fardos)
- **Integração WhatsApp**: Botões diretos para contato via WhatsApp
- **Formulário de Contato**: Opção de contato via email ou WhatsApp

## 📁 Estrutura de Arquivos

```
site/
├── index.html          # Página inicial (Home)
├── produtos.html       # Página de produtos
├── contato.html        # Página de contato
├── styles.css          # Estilos CSS principais
├── script.js           # JavaScript para interatividade
└── README.md           # Documentação
```

## 🚀 Como Usar

1. Abra o arquivo `index.html` em um navegador moderno
2. Navegue pelas páginas usando o menu de navegação
3. Na página de produtos, clique em "Ver Fardo" para ver os detalhes do atacado
4. Use os botões do WhatsApp para contato direto

## 📱 Funcionalidades

### Página Home (index.html)
- **Hero Section**: Destaque visual com logo e chamada para ação
- **Seção Sobre**: História e valores da empresa
- **Vitrine**: 3 produtos em destaque com link para página completa

### Página de Produtos (produtos.html)
- Grid responsivo com 7 produtos
- Modal interativo ao clicar em "Ver Fardo"
- Informações de preço unitário e atacado

### Página de Contato (contato.html)
- Card destacado para WhatsApp
- Formulário de contato funcional
- Informações de contato adicionais

## ⚙️ Personalização

### Alterar Número do WhatsApp
Substitua `5511999999999` nos links do WhatsApp pelos números reais:
- Procure por `wa.me/5511999999999` em todos os arquivos HTML
- Substitua pelo número no formato: `5511999999999` (código do país + DDD + número)

### Alterar Email
Substitua `contato@castanhastorresmo.com.br` pelos emails reais nos arquivos HTML.

### Alterar Imagens
As imagens estão usando URLs do Unsplash. Para usar imagens próprias:
1. Adicione as imagens em uma pasta `images/`
2. Substitua as URLs do Unsplash pelos caminhos locais

## 📝 Notas Técnicas

- **Font Awesome**: Ícones via CDN (já incluído)
- **Imagens**: Placeholders do Unsplash (substituir por imagens reais)
- **JavaScript**: Vanilla JS (sem dependências)
- **CSS**: Mobile-first, sem frameworks
